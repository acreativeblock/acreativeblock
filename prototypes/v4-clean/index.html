Six blocks, six cures.

A block is a symptom — the cure depends on the cause.

01
Directional
"I don't know where to go."

Mechanism Commitment anxiety — choosing one path closes others. Helps Constraints; an actionable, not permanent, direction.

02
Structural
"The project is chaos."

Mechanism The brain can't process undefined complexity. Helps Restructure scope, stages, priorities, dependencies.

03
Execution
"I avoid doing it."

Mechanism The nervous system tags the task as threatening — not laziness. Helps Shrink the task, remove ambiguity, add accountability.

04
Identity
"Am I good enough?"

Mechanism Finishing becomes a verdict on your worth, so you stall. Helps Separate self-worth from output; normalise imperfect release.

05
Skill
"I don't know how."

Mechanism The project exceeds current ability → shame, avoidance. Helps Name the missing skill and the smallest path to it.

06
Environmental
"My context kills it."

Mechanism The environment is incompatible with sustained work. Helps Redesign conditions: sleep, schedule, boundaries, space.
