01The problem

Most advice treats every block as the same problem. It isn't.

Push harder. Wait for inspiration. Just start. A perfectionist doesn't need the same help as someone with no direction; someone burned out doesn't need discipline. So the real work isn't motivation — it's diagnosis.

02The six blocks

A block is a symptom. The cure depends on the cause.

01

Directional

"I don't know where to go."
Mechanism

Commitment anxiety — choosing one path closes others.

What helps

Constraints; an actionable, not permanent, direction.

02

Structural

"The project is chaos."
Mechanism

The brain can't process undefined complexity.

What helps

Restructure scope, stages, priorities, dependencies.

03

Execution

"I avoid doing it."
Mechanism

The nervous system tags the task as threatening — not laziness.

What helps

Shrink the task, remove ambiguity, add accountability.

04

Identity

"Am I good enough?"
Mechanism

Finishing becomes a verdict on your worth, so you stall.

What helps

Separate self-worth from output; normalise imperfect release.

05

Skill

"I don't know how to continue."
Mechanism

The project exceeds current ability → shame, avoidance.

What helps

Name the missing skill and the smallest path to it.

06

Environmental

"My context kills momentum."
Mechanism

The environment is incompatible with sustained work.

What helps

Redesign conditions: sleep, schedule, boundaries, space.
