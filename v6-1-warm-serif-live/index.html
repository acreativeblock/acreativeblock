THE SIX BLOCKS

A block is a symptom — the cure depends on the cause. So the work isn't motivation; it's diagnosis.

01 · Directional

"I don't know where to go."

Not motivation — direction. Commitment anxiety keeps you from committing; we add constraints and an actionable path.

02 · Structural

"The project is chaos."

Vision and drive, but broken architecture. We restructure scope, stages, priorities and dependencies.

03 · Execution

"I avoid doing it."

Not laziness — the nervous system tags the task as threatening. We shrink it, remove ambiguity, add accountability.

04 · Identity

"Am I good enough?"

The project becomes a verdict on your worth, so you stall. We separate self-worth from output.

05 · Skill

"I don't know how."

Often misread as emotional. The project exceeds current ability — we name the missing skill and the smallest path to it.

06 · Environmental

"My context kills it."

The problem is outside. We redesign the conditions — sleep, schedule, boundaries, space.
